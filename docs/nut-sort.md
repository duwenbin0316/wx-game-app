# 木螺母归色

原生小程序 Canvas 2D 游戏，入口 `pages/nut-sort/index`。复用大厅木质 UI、`wood-art` 的木纹与牌匾零件、Clawd、`wood-sfx` 物理建模木音（含木琴叮声与撤销音效）和 `share-card` 分享模板。

## 玩法与进度

- 选中柱子时，柱顶连续同色的螺母成组抬起；移向空柱或顶端同色未满柱时，按目标柱剩余空位一次性批量旋入（计为 1 步，撤销时整批退回）。
- 每种颜色各占满一根柱子，即可过关。七色匠造染木搭配螺母正面居中烙印编号（1–7），辅助辨色。
- 满柱同色归位时自动加盖黄铜螺帽并锁定该柱，防止误触拆散已完成柱。
- 30 关固定种子，颜色数从 3 增至 7；每柱容量分三阶段为 4、5、6。每关根据已知解法步数给出「匠心基准（Par）」与一至三星评定（巧夺天工 / 熟能生巧 / 顺理成章）。
- 不限时，撤销不限次数；重开不损失已解锁关卡。
- 进度、各关最佳步数、静音设置写入 `nut_sort_save_v1`，不同设备不互通。

## 实现

- `miniprogram/utils/nut-sort.js`：纯规则、逆向关卡生成、基准步数与星级评定、已知解法索引、有时间与节点预算的提示搜索。
- `miniprogram/utils/nut-art.js`：精工六角木螺母（倒角冠面、内螺纹孔、立面分明受光與正刻编号）、带容量刻度的螺纹木杆、满柱黄铜螺帽、落点绿圈指引与归位木屑粒子；纯 Canvas 绘图。
- `miniprogram/pages/nut-sort/`：页面、旋出/旋入动画、交互（含极速连点自动结算、提示一步直达、违例轻晃与触感反馈）和存档。静态背景缓存在离屏 Canvas，仅在搬运、轻晃或粒子期间请求动画帧。
- `tests/nut-sort.test.js`：独立规则样例、全部关卡解法回放、星级与防误触、生命周期与存档检查。运行 `node --test tests/nut-sort.test.js`。

关卡从每色一柱的完成状态逆推。只有逆推源移除后为空或仍与被移螺母同色时，才允许该逆推；因此每一步均可按正向规则回放。起局至少留一根空柱，打乱状态的每条记录都携带合法解法。

提示优先使用已知解法的沿途索引；玩家偏离后尝试最多 18,000 节点、160ms 的搜索。预算内未找到时明确提示撤销或重开，不保证任意玩家局面都能即时给出解法。

单指在 12px 位移范围内抬起才作为点选；滑动、多指、取消与跨关触摸不会误搬螺母。切后台时完成当前搬运，并取消动画帧和待执行提示、恢复查找前的提示文字；卸载时关闭音频上下文，停止页面更新。音频不受支持或存储异常不会阻止核心玩法。

## 微信开发者工具验收

本地规则检查与浏览器 Canvas 适配预览不能替代原生小程序验收。无需更改云环境或部署云函数。

1. 导入项目，在大厅打开「木螺母归色」；确认关卡、基准步数、实时星级、归位数和按钮布局。
2. 选柱后确认可落点柱亮起绿圈与槽位虚影，再次点原柱取消；尝试空柱、同色柱、异色柱、满柱与已封帽完成柱，确认规则、轻晃反馈与提示。滑动后松手、双指触摸与系统取消触摸不得搬动螺母。
3. 完成若干步后撤销、重开，确认棋面及步数同步恢复。
4. 点提示，确认起点（↑）与终点（↓）标记，支持直接点终点柱一步归置；走其他路线后再提示，检查预算耗尽的回退说明。
5. 搬运动画中切后台再回来，确认只提交一步，仍可正常移动和撤销；查找提示时立即切后台再回来，确认不会停留在“寻找中”。
6. 通关后查看星级评定、新纪录徽章与三栏统计，进入下一关；重进页面、重新打开小程序，确认解锁、总星数与最佳纪录持久化。
7. 从选关面板进入已解锁关卡；锁定关不可选。第 30 关完成后显示回顾关卡。
8. 小屏与全面屏设备各检查一次，特别是双排柱、底部安全区、选关滚动和玩法弹层。
9. 实机开关音效、切后台、再次点击，确认敲击声与满柱木琴声恢复；分享失败时仍能发送文字和页面路径。
