# 木螺母归色

原生小程序 Canvas 2D 游戏，入口 `pages/nut-sort/index`。复用大厅木质 UI、`wood-art` 的染色木配色与木纹、Clawd、`wood-sfx` 敲击声和 `share-card` 分享模板。

## 玩法与进度

- 一次取最顶端的一枚，只能移至空柱或顶端同色且未满的柱子。
- 每种颜色各占满一根柱子，即可过关。螺母编号对应颜色，辅助辨色。
- 30 关固定种子，颜色数从 3 增至 7；每柱容量分三阶段为 4、5、6。
- 不限时，撤销不限次数；重开不损失已解锁关卡。
- 进度、各关最佳步数、静音设置写入 `nut_sort_save_v1`，不同设备不互通。

## 实现

- `miniprogram/utils/nut-sort.js`：纯规则、逆向关卡生成、已知解法索引、有时间与节点预算的提示搜索。
- `miniprogram/utils/nut-art.js`：六角木螺母、木杆、底座与自适应布局；纯 Canvas 绘图。
- `miniprogram/pages/nut-sort/`：页面、动画、交互和存档。静态背景缓存在离屏 Canvas，只有搬运期间请求动画帧。
- `tests/nut-sort.test.js`：独立规则样例、全部关卡解法回放、生命周期与存档检查。运行 `node --test tests/nut-sort.test.js`。

关卡从每色一柱的完成状态逆推。只有逆推源移除后为空或仍与被移螺母同色时，才允许该逆推；因此每一步均可按正向规则回放。起局至少留一根空柱，打乱状态的每条记录都携带合法解法。

提示优先使用已知解法的沿途索引；玩家偏离后尝试最多 18,000 节点、160ms 的搜索。预算内未找到时明确提示撤销或重开，不保证任意玩家局面都能即时给出解法。

单指在 12px 位移范围内抬起才作为点选；滑动、多指、取消与跨关触摸不会误搬螺母。切后台时完成当前搬运，并取消动画帧和待执行提示、恢复查找前的提示文字；卸载时关闭音频上下文，停止页面更新。音频不受支持或存储异常不会阻止核心玩法。

## 微信开发者工具验收

本地规则检查与浏览器 Canvas 适配预览不能替代原生小程序验收。无需更改云环境或部署云函数。

1. 导入项目，在大厅打开「木螺母归色」；确认关卡、步数、归位数和按钮布局。
2. 选柱后再次点原柱取消；尝试空柱、同色柱、异色柱和满柱，确认规则与提示。滑动后松手、双指触摸与系统取消触摸不得搬动螺母。
3. 完成若干步后撤销、重开，确认棋面及步数同步恢复。
4. 点提示，按起点/终点提示移动；走其他路线后再提示，检查预算耗尽的回退说明。
5. 搬运动画中切后台再回来，确认只提交一步，仍可正常移动和撤销；查找提示时立即切后台再回来，确认不会停留在“寻找中”。
6. 通关后进入下一关；重进页面、重新打开小程序，确认解锁与最佳纪录持久化。
7. 从选关面板进入已解锁关卡；锁定关不可选。第 30 关完成后显示回顾关卡。
8. 小屏与全面屏设备各检查一次，特别是双排柱、底部安全区、选关滚动和玩法弹层。
9. 实机开关音效、切后台、再次点击，确认敲击声恢复；分享失败时仍能发送文字和页面路径。
